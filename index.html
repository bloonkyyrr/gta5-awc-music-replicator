HOW TO GET AUDIO FILES

To get the audio files, make sure you own GTA 5, and have it installed on your PC, then Download OpenIV, then install it. If the OpenIV doesn't work on Enhanced version be sure to use the ZEnhanced Fix.

If you see the game files in openIV, go to x64 > Audio (or if you want the DLC ones go to Update > x64 and select the DLC), and select the audio track, recommended the "interactive_Music.rpf", then select any audio file, then press the Arrow button around "export all" and select "export all multichannel as Stereo WAV" and save it somewhere you'd remember.

Have fun.
